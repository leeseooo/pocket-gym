# 🏋️ Pocket Gym

회사에서 졸릴 때 잠 깨는 **클릭 미니게임 모음** — 작고 눈에 안 띄는 데스크톱 패널 앱.

마우스 클릭만으로 즐기는 작은 운동 게임들. 뒷자리에서 잘 안 보이게 작은 always-on-top 패널로 띄웁니다.

## 게임

| 게임 | 타입 | 조작 |
|---|---|---|
| 🥊 **Combo Bag** | 광클 해소형 | 클릭 → 복서가 랜덤 타격(잽/훅/어퍼/스트레이트/킥), 콤보 카운트 |
| 🏋️ **Unbroken** | 타이밍 집중형 | 크로스핏 행파워 스내치 — 클릭/꾹 누르기/떼기 타이밍으로 언브로큰 렙 *(개발 중)* |

## 특징

- **작은 always-on-top 패널** (300×320) — 몰래 하기 좋게
- **에셋 0장** — 캐릭터·오브젝트·이펙트 전부 코드로 그린 픽셀 도트
- **마우스만으로** — 클릭/홀드/릴리즈 조합
- 메인 화면에서 게임 선택 → 게임 화면 진입, 뒤로가기로 복귀

## 기술 스택

| | |
|---|---|
| 셸 | Tauri 2 (Rust) — 가볍고 은밀 |
| 렌더 | Canvas 2D, 저해상도 버퍼 → 픽셀 확대 |
| 사운드 | Web Audio API |

## 개발

```bash
npm install
npm run tauri dev      # 개발 창 실행
npm run tauri build    # 배포용 .app / .dmg 빌드
```

> 요구사항: Node, Rust(stable).

## 프로토타입

`src/index.html` 은 브라우저로 바로 열어도 동작합니다 (Tauri 없이 확인용).
